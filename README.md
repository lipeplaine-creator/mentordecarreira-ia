## 💬 ROTEIRO DE ENTREVISTAS

**PERGUNTA 1:** O que é machine learning?  
**COMO RESPONDER:** Explique que é um conjunto de técnicas que permitem que sistemas aprendam padrões a partir de dados sem programação explícita.  

**PERGUNTA 2:** Diferença entre aprendizado supervisionado e não supervisionado?  
**COMO RESPONDER:** Supervisionado usa dados rotulados, não supervisionado encontra padrões em dados sem rótulos.  

**PERGUNTA 3:** O que é overfitting?  
**COMO RESPONDER:** Quando o modelo aprende demais os dados de treino e não generaliza bem para novos dados.  

**PERGUNTA 4:** Como garantir qualidade dos dados?  
**COMO RESPONDER:** Fazer limpeza, normalização, tratamento de valores ausentes e análise exploratória.  

**PERGUNTA 5:** Qual biblioteca você usaria para deep learning?  
**COMO RESPONDER:** Citar TensorFlow ou PyTorch, explicando brevemente vantagens.
